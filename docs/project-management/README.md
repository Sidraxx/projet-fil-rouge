# Gestion de projet

Le projet est piloté avec une méthode Scrum adaptée à une équipe étudiante de trois personnes.

## Documents

- `organisation-scrum.md` : rôles, cérémonies et artefacts.
- `definition-ready-done.md` : conditions d'entrée et de sortie des tâches.
- `roadmap-sprints.md` : calendrier des sprints et jalons scolaires.
- `responsabilites.md` : répartition proposée des responsabilités.
- `risques.md` : principaux risques et plans de réponse.
- `demarrer-une-tache.md` : parcours complet d'une Issue jusqu'à sa fermeture.
- `glossaire.md` : définition des termes projet et techniques utilisés dans les documents.

## Outils de suivi

- GitHub conserve le code, les branches, les Issues et les Pull Requests.
- Trello donne une vue simple du travail et de son état.
- Les documents de ce dépôt constituent la référence pour le périmètre et les règles du projet.

Une tâche ne doit pas être dupliquée manuellement avec des informations différentes. La carte Trello doit contenir le lien vers l'Issue GitHub correspondante lorsque du code est nécessaire.

## Documents de référence

- Le périmètre officiel est défini dans `docs/product/perimetre-mvp.md`.
- Les priorités officielles sont définies dans `docs/product/product-backlog.md`.
- Le calendrier officiel est défini dans `roadmap-sprints.md`.
- Les conditions de préparation et de fin sont définies dans `definition-ready-done.md`.
- `CONTRIBUTING.md` traduit ces règles en procédure Git sans les remplacer.
