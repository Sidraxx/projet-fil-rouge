# Documentation produit

Ce dossier regroupe les documents qui définissent ce que le projet doit apporter aux utilisateurs et ce qui doit être développé.

## Documents

- `vision-et-besoin.md` : contexte, problème, utilisateurs et proposition de valeur.
- `perimetre-mvp.md` : contenu du MVP et éléments exclus de cette première version.
- `user-stories.md` : besoins utilisateurs priorisés et critères d'acceptation.
- `product-backlog.md` : liste ordonnée des travaux produit.

## Règle de mise à jour

Toute modification importante du périmètre doit être discutée pendant un Sprint Planning ou une Sprint Review, puis reportée dans ces documents et dans le tableau de suivi.
